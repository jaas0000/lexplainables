# Technische changelog

- Initiële API-features (PR #1, stories 001-002): `api/app/features/feedback/` (indienen, admin-lijst, verwijderen, ongelezen-aantal, markeer-gezien) en `api/app/features/berichten/` (aanmaken, bewerken, publiceren/depubliceren, verwijderen admin; lezen, ongelezen-status, lees-alles analist); `api/app/features/identiteit_toegang/` (eigen gebruikers-tabel, bcrypt, POST /v1/auth/verify); SQLAlchemy Core + Pydantic als "ene bron", Alembic-migraties, pytest-integratietests.
- Eerste frontend: berichten-admin-scherm (PR #2): Eerste frontend-service (`frontend/`) — Next.js admin-scherm voor berichtenbeheer, contractgeneratie API→TypeScript via `openapi-typescript`, CORS-middleware op de API, Playwright E2E-test (gelukkig pad + foutpad), eigen `frontend-ci.yml`, C4-architectuurdocumentatie.
- Huisstijl-frontend (PR #3): Wetsanalyse-kleurtokens als CSS-variabelen in `globals.css`, Fira Sans via `next/font/google`, navigatieheader in `layout.tsx`, en herstructurering van `page.tsx` naar CSS-klassen (`btn`, `field-input`, `tabel`, `badge`, `melding`); E2E-selectorfix `p[role="alert"]` in commit `9c45f09`.
- Auth — Keycloak OIDC-login (PR #4, story 005): Keycloak Authorization Code + PKCE-flow in de frontend (SubtleCrypto, localStorage), JWT-verificatie via JWKS in de API (RS256, cache TTL 300s, asyncio.Lock), `shared/auth.py` vervangt X-Admin-Id header-stand-in door `huidige_beheerder`-dependency met `GebruikerContext`, Playwright E2E via ROPC + `page.addInitScript`, realm-export + CI-opstapstap voor Keycloak 26.
- Auth — eigen gebruikers (PR #5, story 006): Vervangt Keycloak OIDC door eigen `gebruikers`-tabel (bcrypt, SQLModel, Alembic-migratie 0003), `POST /v1/auth/verify` achter API_TOKEN-gate met constant-time vergelijking en timing-oracle-bescherming, Auth.js v5 Credentials provider met httpOnly-sessiecookie, Next.js BFF-routes voor admin-endpoints (`/api/admin/berichten/...`), Keycloak volledig verwijderd uit docker-compose en CI.
- Disclaimer-gate + PoC-strip (PR #7, story 008): server-side middleware-redirect op basis van httpOnly-cookie (`disclaimer_geaccepteerd`), `/disclaimer`-pagina met drie waarschuwingsblokken, PoC-strip in `layout.tsx`, `isDisclaimerExempt()` parallelt `isPublic()`; open-redirect-fix (route geeft gesaniteerde redirect-URL terug); simplify: `TYPE_META`/`TypeBadge`/`SectieHeader`/`LeegePlaceholder` geëxtraheerd naar gedeelde modules, mutatie-state in `beheer/page.tsx` werkt lokaal bij zonder extra GET; favicon + `manifest.webmanifest` toegevoegd.
- Feedback-frontend (PR #8, story 009): zwevende `FeedbackKnop` in `layout.tsx` voor alle ingelogde gebruikers; 5 BFF-routes (`POST /api/feedback`, GET/DELETE/markeer-gezien/ongelezen-aantal voor admin); admin-feedbackpagina (`/beheer/feedback`) met verwijderen + markeer-gezien op mount + 404-race-afhandeling; navigatieknop met ongelezen-badge op `/beheer`. Gedeelde modules: `lib/feedback-types.ts`, `lib/beheer-fetch.ts` (typed `BeheerFetchFout`, vervangt duplicaat in `beheer/page.tsx`), `components/feedback/CategorieBadge.tsx`, `components/feedback/FeedbackItem.tsx`.
- Admin-MCP (PR #6, story 007): Nieuwe TypeScript stdio MCP-server (`tools/wetsanalyse-admin-mcp/`) met vier tools (`list_berichten_admin`, `maak_bericht`, `update_bericht`, `publiceer_bericht`) die de lexplainables admin-API aansturen; auth via `Authorization: Bearer` + `X-User-Id`; vier integratietests met gemockte fetch; `dist/index.js` meegecommit; registreerbaar in `.mcp.json`.
